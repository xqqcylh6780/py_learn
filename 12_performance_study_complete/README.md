# 12_performance_study_complete

Python 性能分析与优化完整学习包，主线目标为 **Python 3.13 / CPython**。

这不是“性能技巧大全”，而是训练一套可靠工作流：**测量 -> 定位 -> 解释 -> 修改 -> 再测 -> 防回归**。

|---:|---|---|---|

## 使用方式

```powershell
cd 12_performance_study_complete
python 01_性能工作流与复杂度.py
python 99_exercises.py
```

每章先阅读文件顶部的概念与误区说明，再运行示例并完成表中对应练习。练习同时包含标准库 API 操作和多输入决策函数，避免只记住某次基准数字。空白练习应为 `0/60`。

## 重要边界

- `sys.getsizeof`、引用计数、字节码、GIL 等部分带有 **CPython 实现细节**，不能当成 Python 语言规范。
- 字节码和解释器优化会随 Python 版本变化，任何微优化都必须在目标版本重新测。
- 性能不等于“速度”一个数字，还可能包含延迟、吞吐、CPU、内存、I/O、启动时间和尾延迟。
- 绝大多数工程中，算法、数据结构、数据库查询、网络往返和 I/O 批次，比语法级微优化重要得多。
